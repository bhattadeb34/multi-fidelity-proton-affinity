## Controlled rerun order

Run from a clean checkout in the recorded environment with:

```bash
PY=python
```

1. DFT descriptor ablations

   ```bash
   $PY scripts/calculations/train_models_dft.py --dataset all
   $PY scripts/calculations/train_models_dft_control.py --control dft-only
   ```

2. Validate each generated CV bundle

   ```bash
   $PY scripts/analysis/validate_result_bundle.py results/nist1155_dft --write-report
   $PY scripts/analysis/validate_result_bundle.py results/kmeans251_dft --group-col record_id --write-report
   $PY scripts/analysis/validate_result_bundle.py results/nist1155_dft_only --write-report
   ```

3. Learning curves, after the DFT bundles pass validation

   ```bash
   $PY scripts/calculations/learning_curve.py --datasets all
   ```

4. Interpretation and derived analyses

   ```bash
   $PY scripts/calculations/compute_shap.py --dataset all
   $PY scripts/analysis/aggregation_analysis.py --results-dir results/kmeans251
   $PY scripts/analysis/tanimoto_bias_analysis.py
   $PY scripts/analysis/compute_cost_analysis.py
   $PY screening/scripts/analysis/summarize_pipeline.py \
     --input-dir data/screening/iter1 \
     --build-report data/screening/iter1/build_report.json \
     --output-dir data/screening/iter1
   ```

5. Regenerate all quantitative figures only after steps 1-4 pass

   ```bash
   $PY make_figures.py --only main --stop-on-error -v
   $PY make_figures.py --only screening --stop-on-error -v
   $PY scripts/plotting/plot_diff_esi.py
   ```
