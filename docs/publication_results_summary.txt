# Validated publication results

This file is the concise numerical record for the controlled August 2026
rerun. All values are in kcal/mol. The corresponding machine-readable result
directories contain predictions, fold metrics, selected features, validation
reports, and SHA-256 manifests.

## Production cross-validation

| Dataset | Split | Best model | MAE (mean +/- fold SD) | Fold feature counts | >=3/5 consensus |
|---|---|---|---:|---|---:|
| NIST (1,155 molecules) | shuffled five-fold KFold | ExtraTrees | 2.8731 +/- 0.2643 | 198, 223, 247, 177, 179 | 150 |
| k-means (251 molecules; 821 sites) | five-fold GroupKFold by molecule | RandomForest | 7.4355 +/- 1.0013 | 77, 86, 60, 125, 79 | 51 |

The NIST rerun changed the prior ExtraTrees estimate from 2.8756 to 2.8731
kcal/mol because one numerically borderline Mordred feature changed in fold 5.
The full current-code rerun and all ten preprocessing-equivalence checks now
match exactly. The k-means model and its 51-feature screening consensus did not
change, so this NIST-only reproducibility correction does not require another
screening, LLM, Pareto, PM7, or prospective DFT run.

fractions). The two k-means curves use molecule-disjoint GroupShuffleSplit
holdouts and group-level subsampling; all 110 k-means cells have zero molecule
overlap. Full-fraction holdout MAEs are:

| Dataset / feature set | Model | Test MAE across five seeds |
|---|---|---:|
| NIST, PM7 + molecular descriptors | ExtraTrees | 2.9287 +/- 0.2153 |

| k-means, PM7 + molecular descriptors | RandomForest | 7.7432 +/- 0.3491 |
| k-means, + DFT descriptors | CatBoost | 5.6228 +/- 0.3560 |

SHAP is descriptive for a final full-data refit. Provenance files verify 150

## Computational cost

Recorded A100 wall time totals are 450.8 GPU-hours for the NIST calculations,
295.1 GPU-hours for the k-means calculations, and 17.10 hours for the corrected
30-candidate prospective job (SLURM 54763379). The measured PM7 + feature +
deployed-model route is 2.855 seconds per molecule on the benchmark machine.
The hardware-crossed speedup is approximately 500x on the NIST timing basis and
1,500x on the k-means timing basis, not 10,000x. These ratios should be quoted
to one significant figure with the hardware caveat.
